## بوابات لا تقبل الاستنتاج من عنوان أو HTTP 200

1. **ترحيل وعزل:** مركز قائم قبل التوسعة ومركز جديد بعدها، ثم إعادة الترحيل. قارن معرفات الطلاب وأرقامهم وهواتفهم وفروعهم والتدقيق ومعرّفات الطلبات قبل/بعد. سجّل alpha وbeta بهوية دخول مشتركة، وجرّب معرفات الصورة والمرفق والنسخة والباركود من المركز الآخر.
2. **رحلة الموظف:** إنشاء أدنى ← تواصل/قوائم/هوية/حقول/صورة/مرفقات/نسخ/مشاركة/باركود ← تسجيل ← حضور وتغطية وتعويض/انتظار/انسحاب/نقل/إتمام ← دفعة وتخصيص وتسوية واسترداد وتصحيح وملاحظة لكل حدث. احفظ النتائج الفعلية والرفض وتاريخ التدقيق، ولا تستبدل السبب الإلزامي بملاحظة.
3. **الإيقاف:** ملف قديم ناقص يبقى قابلًا لحضور النشط والسداد، ثم يرفض الإيقاف الحجز والحضور والتعويض؛ لا ينشئ غيابًا أو تغطية، ولا يمحو التسجيل أو المال. فك الإيقاف لا يكمل النواقص تلقائيًا.
4. **الصلاحيات:** اختبر الطلب المفتوح بعد سحب منحة الهوية أو عضوية الفرع، والتنزيل/النسخة المؤرشفة ورابط الحدث المالي المباشر. افحص الاستجابة والواجهة والسجل، بما فيه غياب عدد أو قيمة محجوبة.
5. **الأداء:** لكل مسار صفحة وتبويب نشط، احفظ عدد استعلامات كل طلب Laravel الذي أحدثه SSR أو الانتقال، ومجموع الطلبات في ذلك الفتح. كرر ببيانات قصيرة وأطول، وبفتح بارد ودافئ. كل عداد حاضر ورقمي، وكل قراءة عادية ≤6 SQL، ومجموع الفتح موثق حتى لو تعددت الطلبات. تحقق من حد الصفحة وعدم نمو الاستعلامات لكل صف.
6. **الواجهة:** سطح مكتب وهاتف ضيق، العربية وRTL، الثيمان، لوحة المفاتيح، تركيز أول خطأ والعودة بعد الإلغاء، تحميل/فارغ/فشل/منع، وحماية التعديلات غير المحفوظة.

## إعادة تشغيل القبول المعزول

جهّز PostgreSQL مستقلًا في `127.0.0.1:5558` بقاعدتي `courses_issue35_browser` و`courses_test_central`، واضبط مفاتيح اتصال Laravel المحلية لهذا المنفذ دون استخدام قواعد alpha/beta المشتركة. شغّل ترحيلات المركز المركزي ثم fixture الدراسة `StudyWithdrawalBrowserFixture.php` لإنشاء alpha وملف الدخول الخاص ذي صلاحية `0600`؛ بعدها شغّل `StudentProfileExpansionBrowserFixture.php` لإضافة beta وهوية الموظف المشتركة وإعادة ترحيل المركزين. يرفض fixture #82 اسم قاعدة أو منفذًا آخر. استخدم Laravel على `8251` وNext.js المبني للإنتاج على `3051`، ثم proxy القياس المتعقب:

```sh
COURSES_PROFILE_EXPANSION_ISOLATED=1 \
COURSES_PROFILE_EXPANSION_PROXY_PORT=8052 \
COURSES_PROFILE_EXPANSION_API_PORT=8251 \
COURSES_PROFILE_EXPANSION_WEB_PORT=3051 \
COURSES_PROFILE_EXPANSION_QUERY_LOG=/tmp/courses-issue82-reads.jsonl \
node apps/web/tests/support/student-profile-expansion-proxy.mjs
```

اضبط `COURSES_INTERNAL_API_ORIGIN='http://{host}:8052'` لعملية Next.js حتى تمر قراءات SSR عبر proxy نفسه؛ سجله يحتفظ بعدد SQL ومدتها من ترويسات Laravel، ويُحسب مجموع طلبات المركز أثناء كل فتح. من `apps/web` أعد رحلة المتصفح:

```sh
COURSES_PROFILE_EXPANSION_ORIGIN=http://alpha.courses.test:8052 \
COURSES_PROFILE_EXPANSION_CREDENTIALS=../api/storage/app/private/issue35-browser-credentials.json \
COURSES_PROFILE_EXPANSION_QUERY_LOG=/tmp/courses-issue82-reads.jsonl \
COURSES_PROFILE_EXPANSION_DB_PORT=5558 \
npx playwright test tests/student-profile-expansion.spec.ts --workers=1
```

الاختبارات الأخرى تستخدم ملف الدخول الخاص نفسه مع متغيرات `COURSES_*_CREDENTIALS` و`COURSES_*_ORIGIN` و`COURSES_*_READ_LOG` الخاصة بها، وتشغّل تسلسليًا على المركزين المعزولين. اختبارات Laravel تستخدم `courses_test_central` في المنفذ نفسه، منفصلة عن قاعدة المتصفح.

### تكامل الرحلة الأكاديمية والمالية

1. غيّرت الرحلة متطلبات المجموعة من 2 إلى 3 وطبقت خطة v2 ذات 4 متطلبات على الطالب نفسه بعد حضوره، ثم سجلت انسحابه. بقيت متطلبات المحاولة التاريخية 4 في API وجدول التسجيل والتغطية، ومتطلبات المجموعة 3، وظهر الانسحاب في تبويب الدراسة. تغطي اختبارات التذاكر المتخصصة التعويض والنقل والإتمام.
2. سوّت الرحلة الرسم إلى 80.00، واستردت 10.00، وصححت الدفعة من 30.00 إلى 40.00، وحفظت ملاحظة مهمة على التصحيح، وخصصت 20.00 ثم صححت التخصيص بالإلغاء. تحرك دين الملخص 80 ← 60 ← 80 EGP، وظهرت الملاحظة والرابط لصاحب الصلاحية. رفضت API طلبات الحساب والملاحظة لموظف التسجيل 404، وحجبت الواجهة الدين والملاحظة عنه.
3. أعاد القبول بعد الدمج ترحيل المركز القائم والجديد مرتين مع حفظ snapshot، وأعاد اختبار مركز بطالب وبيانات موجودة على schema الطلاب القديمة قبل التوسعة. فُتحت التبويبات الثمانية باردًا ودافئًا على سجل قصير وآخر طويل، مع صفحات ثانية فعلية وعداد SQL ومدته؛ كل فتح وقراءة تكامل ≤6 SQL. تسجّل نتائج CI والمراجعة على رأس PR #140 قبل إغلاق #82/#55.

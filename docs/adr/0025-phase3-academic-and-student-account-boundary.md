# نطاق المرحلة الثالثة: الإدارة الأكاديمية وحساب الطالب

تشمل المرحلة الثالثة الكورسات والمراحل الدراسية والمستويات وخططها والمجموعات، وملفات الطلاب والمحاضرين، والتسجيل ومحاولات الدراسة والانتظار والنقل، وجدولة المحاضرات والتدريس الفعلي والحضور والتعويض والإتمام الدراسي، وأدوار الموظفين وتقارير المراجعة اللازمة لهذه العمليات. توسع النطاق ليشمل حساب الطالب المالي البسيط وفق القرار 0011، لأن التسجيل والنقل يحتاجان حفظ الرسوم والدفعات والرصيد والمديونية.

تؤجل بوابات الطالب والمحاضر والامتحانات والشهادات ومحاسبة المحاضرين والمصروفات والفوترة الآلية ومتابعة الطلاب والبيع للمستوى التالي. نسجل الآن من درس المحاضرة ومدته الفعلية دون تنفيذ حساب مستحقاته؛ اخترنا رحلة تشغيل يومية متكاملة للمركز بدل تنفيذ كل وحدات المشروع دفعة واحدة، مع الحفاظ على التاريخ وحدود المركز والفرع التي تعتمد عليها المراحل التالية.

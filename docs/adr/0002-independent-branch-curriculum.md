# استقلال المسار الدراسي لكل فرع

يملك كل فرع تسلسل Course → Stage → Level → Group → Session الخاص به. يمكن نسخ Course وStage وLevel مرة واحدة من فرع آخر، ثم تصبح النسخة مستقلة ولا تنتقل إليها التعديلات تلقائيًا. اخترنا هذا بدل مسار مشترك على مستوى المركز لأن الفروع قد تغيّر محتواها وتتقدم بسرعات مختلفة، مع قبول تكرار بعض المحتوى بين الفروع.

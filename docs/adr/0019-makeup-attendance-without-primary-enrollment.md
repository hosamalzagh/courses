# حضور التعويض دون تغيير المجموعة الأساسية

يضاف الطالب إلى محاضرة مجموعة أخرى بوصفه طالب تعويض، مع بقاء مجموعته الأساسية ومحاولة دراسته والغياب الأصلي دون تغيير. يسمح بحجز التعويض قبل اللقاء أو تسجيل تعويض حضره بالفعل بعد اللقاء حسب الصلاحية، ويربط بمحاولة الدراسة مع التحقق من المحتوى المكافئ؛ لا يمنح الحجز تغطية، وإنما تمنح بعد اعتماد الحضور مع منع تكرار المحتوى.

اخترنا ذلك بدل تسجيل الطالب أساسيًا في مجموعة ثانية لأن التعويض يخص لقاءً ومحتوى ناقصًا، مع قبول حفظ ارتباط خاص بمحاضرة التعويض. تستخدم الواجهة عبارة حضور تعويض لتجنب التباس وصف الطالب بأنه ضيف، ولا ينشئ هذا الحضور محاضرة إضافية للمحاضر.

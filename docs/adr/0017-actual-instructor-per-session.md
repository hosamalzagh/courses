# إسناد التدريس الفعلي إلى كل محاضرة

يقترح النظام محاضري المجموعة عند تسجيل المحاضرة، ويؤكد الموظف من درس فعلًا أو يستبدله بمحاضر بديل أو يضيف مشاركًا، مع تسجيل مدة التدريس الفعلية لكل شخص. اخترنا هذا بدل نسبة كل المحاضرات تلقائيًا إلى محاضر المجموعة لأن البدلاء والمشاركة يجب أن يظهروا في سجل التدريس الذي تعتمد عليه المحاسبة لاحقًا، مع قبول تسجيل التفاصيل لكل لقاء.

قد يدرس محاضران ساعة لكل منهما من لقاء ساعتين، أو يشارك كلاهما طوال الساعتين، وتحتفظ المحاضرة بمدة كل شخص فعلًا. حضور طالب تعويض كضيف في المحاضرة القائمة لا ينشئ محاضرة تدريس إضافية.

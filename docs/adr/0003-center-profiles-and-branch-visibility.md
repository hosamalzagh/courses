# ملفات موحدة داخل المركز وإتاحة مقيدة بين الفروع

نعتمد ملفًا واحدًا للطالب وملفًا واحدًا للمحاضر داخل المركز، مع تسجيلات وإسنادات وسجلات تخص الفروع، بدل إنشاء ملف مستقل للشخص في كل فرع؛ لتجنب تكرار بياناته وتسهيل الاحتفاظ بتاريخه عند العمل أو الدراسة في أكثر من فرع. تبقى الملفات مستقلة بين المراكز حتى عند اشتراك الشخص في هوية دخول مركزية، ولا يشترط إنشاء حساب دخول عند إنشاء الملف.

إتاحة ملفات الطلاب بين الفروع إعداد على مستوى المركز، مقفول افتراضيًا: يرى الموظف الطلاب المرتبطين بفروعه المسندة فقط، وعند فتحه يستطيع صاحب صلاحية البحث عن طلاب المركز العثور على بياناتهم الأساسية خارج هذه الفروع. لا تمنح هذه الإتاحة قراءة السجلات الدراسية أو تعديلها؛ تظل قراءة السجلات والإجراءات عليها محكومة بصلاحيات الفرع والإجراء، ويحتفظ مالك المركز ومسؤوله بنطاق جميع الفروع وفق القرار القائم. تغيير الإعداد يغير الوصول فقط، دون نسخ الملفات أو دمجها أو حذف التسجيلات والتاريخ؛ ونقبل كلفة ضبط واختبار حدود البحث والقراءة والتعديل بدل كلفة الملفات المكررة.

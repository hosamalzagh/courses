# فصل إلغاء المحاضرة عن قرار تعويض الطالب

قد تلغى المحاضرة مع السماح بتعويض الطالب بحضور آخر أو بتعويض مالي، أو دون تعويض، وفق قرار صاحب الصلاحية؛ لا يعني الإلغاء منح تعويض تلقائيًا. اخترنا الفصل ليظل الإلغاء إجراءً دراسيًا والتعويض قرارًا صريحًا، وتخضع المعالجة المالية لضوابط الحركات المعتمدة السابقة بدل حذف الرسوم أو افتراض رد المال.

المحاضرة التي لم تنعقد يمكن إلغاؤها، أما المنعقدة التي تحتاج إلغاء اعتمادها فتستخدم إجراءً منفصلًا بصلاحية وسبب واضحين، مع حفظ سجلها وإظهار أثر الإلغاء على الحضور والتغطية قبل التنفيذ. لا يمحو إلغاء الاعتماد تاريخ المحاضرة ولا ينفذ تعويضًا ماليًا تلقائيًا؛ وإذا امتد الشرح إلى يوم إضافي يمكن اعتماد محاضرة كاملة إضافية وفق القرار 0024 بدل تسجيل حضور جزئي.

الإلغاء مع محاضرة بديلة يبقي العدد المطلوب كما هو وتستبدل البديلة الملغاة، بينما يعتمد صاحب الصلاحية خفض العدد عند إلغاء نهائي دون بديل بعد معاينة أثره على الطلاب. التعويض المالي مستقل ولا يمنح حضورًا أو تغطية دراسية.

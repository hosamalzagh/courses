# حساب مالي واحد للطالب مع حفظ مصدر الحركات

للطالب حساب مالي واحد داخل المركز، مع توضيح الفرع والتسجيل الدراسي الذي تخصه الحركة عند ارتباطها بتسجيل، بدل رصيد منفصل لكل مجموعة؛ قد يستقبل الحساب دفعًا مقدمًا قبل اختيار مجموعة وفق القرار 0013. اخترنا ذلك للاحتفاظ برصيده الدائن أو مديونيته عند تغيير مجموعته، مع قبول كلفة فصل الإتاحة المالية وإسناد الحركات إلى مصادرها. انتقاله إلى الانتظار أو إلى مجموعة أخرى يحفظ الحساب والحركات ولا ينشئ بمجرده استردادًا أو رسومًا جديدة. حسم القرار 0011 نطاق تنفيذ حساب الطالب المالي في المرحلة الثالثة.

تظهر المديونية تنبيهًا عند إلحاق الطالب بمجموعة أو نقله لفرع آخر، ويقرر الموظف مقدم الطلب والمخول بالإجراء الاستمرار أو التراجع؛ لا تمنع المديونية الإجراء ولا تتطلب صلاحية تجاوز مالي لمجرد الاستمرار. يحل هذا القرار محل الخيار السابق لإعداد منع التسجيل أو النقل بسبب المديونية، وتظل المديونية محفوظة كما لا تمنع النقل للانتظار. يسمح باستخدام الرصيد الدائن في تسجيل بفرع آخر بموافقة صاحب صلاحية مالية، مع تسجيل استخدامه على التسجيل الجديد وحفظ مصدره الأصلي؛ لا يستخدم النقل الأكاديمي الرصيد تلقائيًا. اخترنا فصل قرار التسجيل والنقل عن التصرف المالي لتجنب تعديل الحقوق المالية ضمن تغيير أكاديمي غير صريح.

يرى موظف الحسابات الحركات الخاصة بالفروع المسندة إليه فقط. استخدام الرصيد بين فرعين يحتاج صلاحية مالية على الفرعين وصلاحية الاعتماد، أو ينفذه مالك المركز أو مسؤوله ضمن صلاحياتهما؛ ولا يفتح منح الاعتماد المالي وحده سجلات كل الفروع.

عند وجود رصيد متاح للطالب يعرض النظام الرصيد ضمن حدود صلاحيات الموظف ويقترح استخدامه أولًا، ويختار الموظف استخدامه أو تسجيل دفعة جديدة من الطالب. الاقتراح لا يخصص الرصيد تلقائيًا ولا يجعل وجوده مانعًا لاستلام دفعة أخرى، وتظل صلاحيات الاستخدام بين الفروع المعتمدة مطبقة.

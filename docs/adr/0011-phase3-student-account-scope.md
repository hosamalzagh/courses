# إضافة حساب الطالب المالي البسيط إلى المرحلة الثالثة

تشمل المرحلة الثالثة حساب الطالب المالي البسيط: تسجيل المبالغ المستحقة والمدفوعات والتسويات مع أسبابها، وعرض الرصيد وتاريخ الحركات حسب الصلاحية. وسعنا النطاق الأكاديمي بهذا القدر لأن التعامل الفعلي مع الرصيد والمديونية أثناء التسجيل والنقل يحتاج حركات مالية، بدل الاكتفاء بذكر رصيد بلا مصدر؛ وتؤجل محاسبة المحاضرين والمصروفات والفوترة الآلية للمراحل التالية حتى لا يتحول هذا التوسع إلى تنفيذ الماليات كاملة.

# تصحيح الحضور المغلق بصلاحية وسجل تغيير

يسمح بتصحيح حضور الطالب بعد إغلاق المحاضرة من صاحب صلاحية تصحيح الحضور فقط، مع تسجيل السبب والقيمة السابقة والجديدة ومن صحح. يعاد حساب تغطية المحتوى وعدادات الغياب وتقرير المراجعة وفق الحضور المصحح، دون نقل الطالب أو إعادته إلى مجموعة تلقائيًا؛ يظل إلغاء اعتماد المحاضرة إجراءً منفصلًا.

اخترنا التصحيح المقيد مع حفظ التاريخ بدل منع التصحيح أو تعديل السجل بصمت لأن الخطأ في الحضور يؤثر على تقدم الطالب وقرار مراجعة الغياب، مع قبول كلفة تحديث الحسابات التابعة وحفظ أثر التغيير.

يسمح باستثناء للتراجع عن آخر تسجيل أجراه الموظف نفسه داخل محاضرة مفتوحة إذا لم يعدله موظف آخر، دون صلاحية تصحيح إضافية، مع حفظ السجل؛ ولا يمتد الاستثناء إلى المحاضرة المغلقة أو إلغاء اعتماد المحاضرة.

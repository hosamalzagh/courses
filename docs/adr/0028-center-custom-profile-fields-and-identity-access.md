# حقول إضافية للمركز مع حفظ القيم وتقييد بيانات الهوية

تبقى بيانات الطالب الأساسية ثابتة، ويعرّف مالك المركز أو مسؤوله حقولًا إضافية مشتركة بين فروعه بأنواع محددة بدل إضافة حقل ثابت لكل احتياج خاص مثل `skillcard`. يحفظ تعطيل الحقل قيمه السابقة ولا يفرضه على الحفظ اللاحق ولو كان مطلوبًا قبل تعطيله، ويحتاج تغيير نوعه بعد حفظ قيمة له إلى حقل جديد؛ يلزم الحقل النشط المطلوب عند إنشاء الملف أو تعديل بياناته، وتظهر نواقص الملفات القديمة دون تعطيل الحضور أو السداد، لنقبل اختلاف احتياجات المراكز مع حفظ معنى التاريخ.

تحتاج أرقام الهوية والجواز ومرفقات الهوية صلاحية إضافية يمنحها المالك، ويملكها المالك ومسؤول المركز افتراضيًا؛ ولا تتوسع نتائج البحث بين الفروع بالحقول الجديدة، حتى لا يتحول توسيع الملف إلى توسيع تلقائي للوصول إلى بياناته. تظل صلاحيات الحساب المالي وحدود الفروع قائمة.

يصنف المسؤول كل حقل إضافي بأنه عام داخل الملف أو بيان هوية؛ لا تكفي منحة الهوية وحدها للوصول إلى التصنيف الثاني: تتطلب القراءة حق قراءة ملف الطالب في فرع مرتبط به ومنحة الهوية، ويتطلب التعديل حق إدارة ملفه في فرع مرتبط به ومنحة الهوية. تبقى القيم المحجوبة محفوظة عند تعديل بيانات أخرى، ولا يظهر أي حقل إضافي في البحث بين الفروع.

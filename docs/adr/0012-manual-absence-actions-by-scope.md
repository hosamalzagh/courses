# مراجعة الغياب وإجراء النقل بقرار الموظف

بلوغ حد الغياب ينشئ حالة للمراجعة في تقرير أو تنبيه، ولا ينقل الطالب تلقائيًا؛ يختار الموظف صاحب الصلاحية الإجراء يدويًا، ويمكنه العمل من نطاق الفرع كله أو الكورس أو المرحلة الدراسية أو المستوى داخل الفروع المسندة إليه ونطاق صلاحياته. يظل الطالب مرتبطًا بمجموعته حتى ينفذ الموظف النقل، والعودة من الانتظار أو العودة بعد تصحيح غياب تكون بقرار يدوي كذلك.

اخترنا إبقاء القرار لدى الموظف بدل التحويل التلقائي لأن عدد الغيابات يستدعي مراجعة حالة الطالب قبل تغيير تسجيله، مع قبول تأخر الإجراء حتى المراجعة. يحل هذا القرار محل التحويل التلقائي المذكور سابقًا.

يختار الموظف طلابًا محددين أو كل المستحقين داخل نطاق التقرير، ثم يعاين العدد والأسماء قبل تنفيذ النقل للانتظار. يعاد التحقق من حالة كل طالب قبل التنفيذ؛ من تغيرت حالته بما يمنع الإجراء يستبعد مع توضيح السبب، بدل تطبيق القرار اعتمادًا على تقرير قديم.

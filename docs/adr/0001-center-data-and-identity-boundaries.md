# حدود بيانات المركز والهوية

المركز هو الجهة المتعاقدة، وله قاعدة PostgreSQL مستقلة حتى تُعزل بياناته ويمكن استعادته دون إرجاع بيانات بقية المراكز. تبقى هوية المستخدم وعضويته الأساسية وأدوار المنصة في القاعدة المركزية؛ وتبقى الفروع وأدوار المركز وصلاحياته وإسنادات الموظفين في قاعدة المركز. يرى مالك المركز ومسؤوله جميع فروعه، بينما تُقيّد بقية أدوار الموظفين بإسنادات الفروع، ولا تمنح أدوار المنصة حق قراءة بيانات المراكز. اخترنا هذا التقسيم بدل حفظ جميع الأدوار مركزيًا لأن دور الشخص قد يختلف من فرع إلى آخر، مع قبول كلفة إدارة قواعد متعددة والتحقق الصريح من حدود الاتصال والجلسات والمهام والنسخ.

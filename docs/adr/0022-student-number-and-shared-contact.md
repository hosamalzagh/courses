# تعريف الطالب برقم داخلي مع السماح برقم تواصل مشترك

لكل طالب رقم داخلي فريد داخل المركز، ويسمح بتكرار رقم التواصل بين ملفات الطلاب، مثل أخوين يستخدمان رقم ولي الأمر. يظهر تنبيه عند تشابه البيانات لتجنب ملف مكرر، دون دمج تلقائي أو اعتبار الهاتف هوية الطالب؛ اخترنا ذلك بدل فرض تفرد الهاتف حتى لا يمنع تسجيل أشخاص مختلفين يشتركون في وسيلة تواصل، مع قبول مراجعة التنبيهات يدويًا داخل حدود الإتاحة المعتمدة.

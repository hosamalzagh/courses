# تثبيت متطلبات الدراسة على إصدار محدد للخطة

ترتبط المجموعة بإصدار محدد من خطة المستوى، وتحتفظ محاولة الطالب بالإصدار الساري ومتطلبات الدراسة في كل فترة من تاريخها، بما فيه انتقالها إلى فرع آخر وفق القرار 0026. تنشئ التعديلات الدراسية إصدارًا جديدًا بدل تغيير متطلبات الطلاب الحاليين ونسب تغطيتهم تلقائيًا؛ والانتقال إلى إصدار جديد إجراء صريح يوضح المحتوى المحتسب والمتطلبات الجديدة ويحفظ التاريخ. اخترنا ذلك لحفظ معنى التقدم والتاريخ، مع قبول إدارة إصدارات متعددة وتعاقب متطلبات الدراسة داخل المحاولة نفسها.

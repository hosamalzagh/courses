# مشاركة البحث باختيار الطالب وإعداد المركز معًا

نضيف اختيار مشاركة لكل ملف طالب إلى إعداد إتاحة البحث على مستوى المركز المعتمد في القرار 0003، لأن المركز قد يرغب في مشاركة بعض الملفات دون جميعها. يحدد المركز القيمة الافتراضية، ويمكن لموظف التسجيل المخول بتعديل الملف أو مالك المركز أو مسؤوله تغيير اختيار الطالب مع تسجيل التغيير؛ ولا يظهر الملف خارج فروعه إلا باجتماع اختيار المشاركة وإعداد المركز وصلاحية البحث للموظف.

يظل الظهور مقتصرًا على الاسم والرقم الداخلي وهاتف الملخص فقط؛ لا تظهر جهات التواصل المسماة أو مالكو قنوات المتابعة أو بيانات الهوية أو الحقول الإضافية، ولا يمنح البحث حق فتح سجلات فرع آخر. نقبل إدارة اختيار لكل طالب مقابل ضبط المشاركة بشكل أدق، مع استمرار استقلال ملفات المراكز وصلاحيات الفروع.

تهيئ القيمة الافتراضية اختيار المشاركة عند إنشاء ملف جديد؛ تغييرها لاحقًا لا يغير اختيارات الملفات الموجودة تلقائيًا. يبقى تغيير اختيار طالب إجراءً صريحًا محفوظًا في سجل التغيير.

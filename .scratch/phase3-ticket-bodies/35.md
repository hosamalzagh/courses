## What to build

تشغيل رحلة موظفين كاملة قابلة للتكرار عبر مركزين وفروع متعددة وإثبات النتائج والعزل والأداء.

## Acceptance criteria

- [ ] تهيئة موثقة قابلة للتكرار ثم تنفيذ ملفات الأشخاص والمنهج والمجموعة والتسجيل المتأخر والدفعات والتدريس والحضور والانتظار والنقل والتعويض والإتمام والتسوية والاسترداد والتصحيح.
- [ ] التحقق من تفاعل التغييرات: حفظ قرارات الإتمام بعد التصحيح وتعديل المتطلبات، وتعويض ثم اعتماد طالب بعد اكتمال المجموعة، وعدم تأثر المركز الآخر.
- [ ] التحقق من العربية وRTL والشاشتين الواسعة والضيقة والثيمين ولوحة المفاتيح والتركيز وحالات التحميل والفشل والمنع.
- [ ] قياس الصفحات العادية بحد ستة استعلامات فعليًا عبر Laravel بما فيها قراءات Next.js، ببيانات قصيرة وأطول وقياسات باردة ودافئة دون عدادات مفقودة تعتبر صفرًا.
- [ ] فحص ترحيل المراكز القائمة والجديدة وعزل العامل الخلفي عند استخدامه، وتشغيل اختبارات الأساس المناسبة؛ القبول محلي ولا يدعي نشر إنتاج.
- [ ] تتضمن الرحلة تصحيح تخصيص خاطئ مع صحة الدفعة، وتصحيح رسوم أو تسوية واسترداد مسجلين خطأ، وتثبت عدم اختراع حركة نقدية فعلية من التصحيح.

### متطلبات مشتركة لهذه الرحلة

- [ ] مسار كامل عبر التخزين الدائم وعمليات HTTP المحمية وواجهة الموظف واختبارات قبول المتصفح؛ لا تقتصر التذكرة على طبقة واحدة.
- [ ] توسيع ترحيلات المركز عند الحاجة دون جداول تشغيل مركزية أو ربط قواعد المراكز، واختبار نجاحها للمركز القائم والجديد.
- [ ] التحقق من الصلاحية ونطاق الفرع والمركز عند كل طلب ومنع الوصول بالمعرف المباشر؛ إعادة التحقق عند التأكيد وعدم كشف بيانات فرع محجوب.
- [ ] سجل آمن للفاعل والنطاق والوقت والسبب حيث يلزم والروابط أو القيم السابقة واللاحقة، ظاهر عبر سجل التدقيق الموجود ضمن الصلاحيات.
- [ ] واجهة عربية RTL ضمن الإطار والجداول القائمة، تدعم الثيمين والشاشة الضيقة والوصول بلوحة المفاتيح وحالات التحميل والتحقق والفشل والمنع واستعادة التركيز.
- [ ] اختبار رحلة متصفح مصرح بها ومرفوضة عبر Laravel وPostgreSQL الحقيقيين، مع اختبارات HTTP مركزة للتزامن والقواعد والعزل عند الحاجة دون محاكاة الحدود الأساسية.
- [ ] حد ستة استعلامات لقراءات الصفحة العادية عبر الاتصالات المركزية واتصال المركز، دون نمو لكل صف أو تحميل شامل غير محدود؛ القياس يشمل قراءات الخادم.
- [ ] الكتابات المرتبطة ذرية؛ إعادة الإرسال والمعاينة القديمة والتزامن لا تنتج مالًا أو حضورًا أو اعتمادًا مكررًا، وتظهر التعارضات بصورة قابلة للاسترداد.
- [ ] التذكرة التي تنفذ لاحقًا بين ميزتين متداخلتين تضيف اختبار تكاملهما المحدد؛ لا يكفي تعبير «إذا كانت الميزة موجودة» لإسقاط القبول. تسجل الرحلة المنفذة أولًا التداخل المتبقي في تسليمها، ثم تتحقق رحلة القبول النهائية من اكتماله. تظل اختبارات كل تذكرة ضمن نطاقها إلزامية.
- [ ] مرجعية المصطلحات والقرارات هي قاموس المشروع والقرارات 0001–0026 والمواصفة الأم؛ لا يضاف انتظار أولي قبل أول مجموعة أو بوابات أو امتحانات أو شهادات أو محاسبة محاضرين أو نشر إنتاج ضمن هذه المرحلة.
